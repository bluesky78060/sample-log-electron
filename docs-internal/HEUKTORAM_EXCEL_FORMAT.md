# 흙토람 엑셀 내보내기 서식 명세서

## 개요

흙토람(Heuktoram) 모듈에서 생성하는 엑셀(.xlsx) 파일의 상세 서식 명세. v1.7.66~v1.7.67에서 대폭 개선됨.

## 기본 정보

- **패키지**: `xlsx-js-style` (셀 스타일링 지원, 기존 `xlsx`에서 변경)
- **시트명**: '일괄등록양식'
- **총 컬럼 수**: 48개 (A~AV) - 기존 56컬럼에서 8개 제거
- **파일명**: `흙토람_토양검정_{연도}_{날짜}.xlsx`

| 셀 범위 | 내용 |

| A2:H2 (병합) | '※ 300건 이하로 입력해주세요. 주소매핑여부와 기타주소 컬럼은 빈값으로 두세요.' |

### 3행: 대분류 헤더

- **배경색**: 연한 파란색 (#B4C6E7)
- **폰트**: 굵게, 10pt
- **정렬**: 가운데(가로/세로), 텍스트 줄바꿈

### 4행: 소분류 헤더

- **배경색**: 연한 노란색 (#FCE4B5)
- **폰트**: 굵게, 9pt
- **정렬**: 가운데(가로/세로), 텍스트 줄바꿈

### 5행~: 데이터

- **배경색**: 없음(흰색)
- **정렬**: 가운데(가로/세로), 텍스트 줄바꿈
- **테두리**: 얇은 회색선 (#808080), 상하좌우

## 데이터 변환 규칙

### 면적 (S열, 인덱스 18)

- 단위가 '평(pyeong)'이면 ㎡로 자동 변환: `Math.round(평수 × 3.3058)`
- 단위가 ㎡이면 그대로 출력
- 예: 평수 300 → 약 992 ㎡

### 용도구분 코드 (G열, 인덱스 6)

| 코드 | 라벨 |
|------|------|
| 0 | 일반적인토양검정-0 |
| 1 | 토양개량제 규산-1 |
| 2 | 토양개량제 석회질-2 |
| 3 | 녹비작물-3 |

**우선순위**: 개별 검정결과 usageCode > 네비바 일괄 용도구분 > 기본값 '0'

### 시행전후 (H열, 인덱스 7)

| 용도코드 | 시행전후 값 | 의미 |
|----------|------------|------|
| 0 | (빈값) | 해당 없음 |
| 1, 2, 3 | N | 시행전 |
| 1, 2, 3 | Y | 시행후 |

### 전화번호 (AV열, 인덱스 47)

- 하이픈(-) 자동 제거
- 예: 010-1234-5678 → 01012345678

### 경지구분 1차 (E열, 인덱스 4)

- 고정값: '농가의뢰'
- 모든 행에서 동일

### 필지 분류 (A열, 인덱스 0)

```javascript
row.isSubLot ? '하위필지' : '필지'
```

### 지번 구분 (N열, 인덱스 13)

```javascript
isMountain ? '산' : ''
```

## 구현 메서드

### buildWorksheetData(rows)

**역할**: 헤더 4행 + 데이터 행 생성, 48컬럼 배열 반환

**입력**:
- `rows`: 검정결과 배열

**출력**:
- 2D 배열: 첫 4행은 헤더, 5행부터 데이터

**처리 흐름**:
1. 제목행(A1) + 안내문행(A2) 생성
2. 대분류 헤더(3행) + 소분류 헤더(4행) 생성
3. 각 row에 대해 48컬럼 데이터 배열 생성
4. 전체 배열 반환

### getColumnWidths()

**역할**: 48개 컬럼 너비(wch) 배열 반환

**출력**: 길이 48의 배열, 각 요소는 너비 값

```javascript
[12, 10, 12, 20, 10, 8, 20, 16, 10, 8, 10, 10, 8, 10, 8, 8, 14, 10, 10, 14, 10, ...]
```

### applyHeaderStyles(ws, wsData)

**역할**: 3~4행 배경색/폰트 + 5행 이후 가운데정렬/테두리 적용

**입력**:
- `ws`: 워크시트 객체
- `wsData`: 셀 데이터 배열

**처리**:
1. 3행 셀 순회 → 배경색 #B4C6E7, 폰트 굵게 10pt
2. 4행 셀 순회 → 배경색 #FCE4B5, 폰트 굵게 9pt
3. 5행 이후 모든 셀 → 가운데 정렬, 텍스트 줄바꿈, 회색 테두리

### applyHeaderMerges(ws)

**역할**: 1~2행 + 3~4행 셀 병합 설정

**병합 대상**:
- A1:C1 (제목)
- A2:H2 (안내문)
- B3:B4, C3:C4, ... (세로 병합 23개)
- E3:F3, G3:H3, J3:M3, ... (가로 병합 6개)

**구현**: `ws.mergeCells()` 메서드 반복 호출

### exportToExcel()

**역할**: 위 메서드들을 조합하여 .xlsx 파일 생성/다운로드

**처리 흐름**:
1. `buildWorksheetData(rows)` 호출하여 wsData 생성
2. Workbook 및 Worksheet 생성
3. `applyHeaderMerges(ws)` → 셀 병합
4. `applyHeaderStyles(ws, wsData)` → 스타일 적용
5. `getColumnWidths()` → 컬럼 너비 설정
6. `XLSX.writeFile(wb, filename)` → 파일 다운로드

## 주의사항

### 일괄등록 제약사항

- **최대 행 수**: 300건 이하
- **주소매핑여부(Q열)**: 빈값 유지 (한국농업기술센터 시스템에서 자동 처리)
- **기타주소(R열)**: 빈값 유지 (단일 주소 형식으로 통일)

### 데이터 검증

엑셀 생성 시 필수 검증 항목:

- [ ] 시료번호(I열) 중복 없음
- [ ] 면적(S열) 양수
- [ ] 주소 필드 필수 입력 (J~M열, O~P열)
- [ ] 전화번호(AV열) 형식 정상 (- 제거 후)

### 브라우저 호환성

- `xlsx-js-style` 사용 시 IE11 미지원
- Chrome, Firefox, Safari, Edge 최신 버전 권장
- 파일 다운로드: `XLSX.writeFile()` 사용
