② 판정 로직

자동 판정 기준

  • 적합 — 검출량 ≤ MRL 기준값 (예: 0.015 ≤ 0.05)
  • 부적합 — 검출량 > MRL 기준값 (예: 0.080 > 0.05)
  • - — MRL 기준값 DB에 없음 (카바릴/사과 같은 케이스) → 사용자가 수동 판정

전체 판정 자동 연동

  • 모든 검출 농약이 적합 → 상단 판정 칩이 자동으로 불검출으로 표시됨 (제안)
  • 하나라도 부적합 → 자동으로 검출 (부적합) 표시
  • 사용자는 수동으로 변경 가능 (최종 결정권은 사용자)
