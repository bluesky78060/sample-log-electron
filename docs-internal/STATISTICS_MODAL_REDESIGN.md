# 토양 접수 통계 모달 개선 기획서

## 1. 현재 상태 분석

### 1.1 현재 구조

```
토양 접수 통계 모달 (statisticsModal)
├── 상단 카드 3개 (총 접수 / 완료 / 미완료)
├── 구분별 통계 (세로 막대 차트 - renderVerticalBarChart)
├── 목적(용도)별 통계 (가로 막대 차트 - renderHorizontalBarChart)
├── 월별 접수 현황 (스택 세로 막대 - renderMonthlyChart)
├── 분기별 요약 (프로그레스 바 - renderQuarterlySummary)
├── 접수 방법별 (카드 - renderMethodCards)
└── 닫기 버튼
```

### 1.2 현재 데이터 항목

| 항목 | 데이터 | 차트 종류 | 위치 |
|------|--------|-----------|------|
| 총 접수/완료/미완료 | 숫자 3개 | 카드 | 상단 |
| 구분별 | 논/밭/과수/시설/임야/성토/기타 | 세로 막대 | 좌측 |
| 목적(용도)별 | 일반재배/유기/무농약/GAP/저탄소 | 가로 막대 | 우측 |
| 월별 | 1~12월 (완료/미완료 스택) | 세로 막대(스택) | 하단 |
| 분기별 | Q1~Q4 완료율 | 프로그레스 바 | 하단 |
| 접수 방법별 | 우편/이메일/팩스/직접방문 | 카드 | 하단 |

### 1.3 현재 렌더링 메서드

| 메서드 | 역할 | 파일 |
|--------|------|------|
| `calculateStatistics()` | 전체 데이터 집계 | soil-script.js:2350 |
| `openStatisticsModal()` | 모달 열기 + 렌더링 호출 | soil-script.js:2446 |
| `renderVerticalBarChart()` | 구분별 세로 막대 | soil-script.js:2470 |
| `renderHorizontalBarChart()` | 목적별 가로 막대 | soil-script.js:2502 |
| `renderMonthlyChart()` | 월별 스택 막대 | soil-script.js:2584 |
| `renderQuarterlySummary()` | 분기별 완료율 | soil-script.js:2641 |
| `renderMethodCards()` | 접수 방법별 카드 | soil-script.js:2535 |
| `renderBarChart()` | 범용 막대 (미사용?) | soil-script.js:2559 |

### 1.4 현재 문제점

1. **상단 카드 디자인이 밋밋함** - 완료율(%)이 직관적이지 않음, 원형 프로그레스 링 없음
2. **구분별 세로 막대가 정보 밀도 낮음** - 건수만 표시, 비율(%) 미표시
3. **월별 차트 높이 부족** - 12월까지 작은 막대, 데이터가 없는 달은 빈 공간
4. **분기별/접수방법별은 활용도 낮음** - 사용자가 거의 보지 않는 정보
5. **차트 클릭 인터랙션 없음** - 차트 클릭 시 해당 필터로 이동 불가
6. **엑셀 내보내기 없음** - 통계 데이터 외부 활용 불가
7. **다크모드 지원 불완전** - 일부 차트 색상이 다크모드에서 안 보임
8. **다른 시료 타입과 비일관** - 토양만 통계 모달 있고, 나머지는 없거나 다름

## 3. 개선 제안

### 3.1 추천 방향: A + B 조합

현재 앱의 녹색 테마(시안 A)를 유지하면서, 시안 B의 높은 정보 밀도를 결합합니다.

### 3.2 UI 개선 항목

#### 상단 카드 영역

| 항목 | 현재 | 개선 |
|------|------|------|
| 완료율 표시 | 없음 | **원형 프로그레스 링** (91.4%) 추가 |
| 카드 디자인 | 단순 숫자+라벨 | 아이콘 + 숫자 + 라벨 + **비율(%)** |
| 카드 배경 | 연한 색상 박스 | 그라디언트 또는 토널 레이어링 |

#### 구분별/목적별 차트

| 항목 | 현재 | 개선 |
|------|------|------|
| 구분별 차트 | 세로 막대 (건수만) | **가로 막대** + 건수 + **비율(%)** |
| 목적별 차트 | 가로 막대 (건수만) | 가로 막대 + 건수 + **비율(%)** |
| 색상 | 단색 | 카테고리별 **그라디언트** 또는 **파스텔** |
| 정렬 | 건수 내림차순 | 유지 |

#### 월별 차트

| 항목 | 현재 | 개선 |
|------|------|------|
| 차트 종류 | 스택 세로 막대 | **그룹 세로 막대** (완료/미완료 나란히) |
| 높이 | 작음 (~150px) | **250px** 이상으로 확대 |
| 라벨 | 건수만 | 건수 + **완료율%** |
| 빈 달 | 빈 공간 | 0건 표시 + 회색 점선 |

#### 추가 기능

| 기능 | 현재 | 개선 |
|------|------|------|
| 엑셀 내보내기 | 없음 | **통계 데이터 엑셀 다운로드** 버튼 추가 |
| 차트 클릭 | 없음 | 클릭 시 해당 필터 적용 후 모달 닫기 (Phase 2) |
| 인쇄 | 없음 | 인쇄 최적화 CSS (Phase 2) |

#### 제거/축소 항목

| 항목 | 현재 | 제안 |
|------|------|------|
| 분기별 요약 | 프로그레스 바 4개 | **제거** (월별에서 이미 파악 가능) |
| 접수 방법별 | 카드 4개 | **제거** 또는 접기(토글) |

## 4. 기술 구현 계획

### 4.1 Phase 1: 디자인 개선 (CSS + HTML)

**범위**: 기존 데이터 구조 유지, 시각적 개선만

1. 상단 카드 리디자인 (4열: 총접수/완료/미완료/완료율 링)
2. 구분별: 세로 막대 → 가로 막대 + 비율%
3. 월별 차트 높이 확대 (250px)
4. 분기별/접수방법별 섹션 제거 또는 토글
5. 다크모드 차트 색상 보완
6. 모달 푸터에 "엑셀 내보내기" + "닫기" 버튼

**수정 파일**:
- `src/soil/soil-script.js` — 렌더링 메서드 수정
- `src/soil/soil-style.css` — 차트 스타일
- `src/soil/index.html` — 모달 HTML 구조

### 4.2 Phase 2: 기능 추가

1. 통계 엑셀 내보내기 (XLSX)
2. 차트 클릭 → 필터 연동
3. 완료율 원형 프로그레스 링 (CSS-only, canvas 불필요)
4. 월별 차트에 완료율% 라벨

### 4.3 Phase 3: 5개 시료 타입 공통화

현재 토양만 통계 모달이 있으므로, 개선된 통계를 `BaseSampleManager`에 공통 메서드로 추출하여 5개 시료 타입(토양/수질/퇴액비/중금속/잔류농약)에서 재사용.

**공통화 대상**:
- `calculateStatistics()` — 카테고리/목적 매핑만 시료별로 다름
- `openStatisticsModal()` — HTML 구조 동일
- `renderHorizontalBarChart()` — 범용 재사용
- `renderMonthlyChart()` — 범용 재사용

### 4.4 수정 규모 추정

| Phase | 파일 수 | 추정 코드량 | 우선순위 |
|-------|---------|-------------|----------|
| Phase 1 | 3 | ~300줄 수정 | 높음 |
| Phase 2 | 2 | ~150줄 추가 | 중간 |
| Phase 3 | 10+ | ~500줄 리팩터링 | 낮음 |
