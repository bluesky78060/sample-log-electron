# SAMPL-1-163 코드 리뷰 — 점검이 '데이터 없음'의 이유를 말하지 못한다

## 담당자가 실제로 막혔다

SAMPL-1-155가 만든 도구를 담당자가 실행했더니 결과가 이것뿐이었다.

```text
저장된 토양 데이터가 없습니다.
```

담당자는 실데이터를 가진 사용자다. 이 한 문장으로는 **다음에 무엇을 해야 할지 알 수 없다.**

## 한 문장이 네 상황을 덮고 있었다

| 실제 상황 | 담당자가 할 일 |
| --- | --- |
| 토양 키가 아예 없다 | **환경이 다르다** — Electron 앱과 웹은 별개 저장소다 |
| 키는 있는데 0건 | 정상. 아직 접수가 없다 |
| 다른 시료는 있는데 토양만 없다 | 저장소는 맞다 — 토양만 없다 |
| Firestore에만 있다 | 로컬 캐시가 비었다 |

**이 도구의 존재 이유가 "조용한 거짓말을 없애는 것"인데 도구 자신이 모호했다.**
`⛔ 읽지 못한 저장소` 경고는 넣었으면서 **애초에 저장소를 못 찾은 경우**는 다루지 않았다.

## 이중 환경을 화면이 말하지 않았다

`CLAUDE.md`가 명시하는 이 앱의 중심 불변식이다. Electron 렌더러의 localStorage와
브라우저의 localStorage는 **완전히 별개**다. 앱으로 접수하고 웹 설정에서 점검하면
**정상 데이터가 있어도 0건**이 나온다. 담당자는 데이터가 사라졌다고 오해하게 된다.

## 수정

`diagnoseEmptyResult` 순수 함수를 추가해 네 경우를 구분하고, 실행 환경(Electron/웹)과
Firestore가 범위 밖임을 **화면에** 적는다(전에는 리뷰 문서에만 있었다).

## 독립 리뷰 레인

- **gemini: 미수행** — `GOOGLE_CLOUD_PROJECT` 미설정. **실행하지 않은 검증을 통과로 적지 않는다.**
- **codex: 수행** — CRITICAL 0 / MAJOR 0 / **MINOR 2** / SUGGESTION 3

### codex 지적과 대응

| 심각도 | 지적 | 대응 |
| --- | --- | --- |
| MINOR | `countOtherTypeStores`가 **저장소 규칙 밖의 키**(`waterSampleLogs_backup`)까지 세고, 한 타입의 두 연도를 "2종"으로 표시해 담당자가 시료 종류로 오해한다 | 연도 4자리 또는 레거시만 인정하도록 정규식으로 좁히고, **타입 수**(Set)를 센다 |
| MINOR | **읽지 못한 토양 키가 "키 없음"으로 재분류된다.** `reports`에는 파싱 성공분만 들어가므로 손상 JSON이 있으면 `soilKeyCount: 0`이 되어, 위의 `⛔ 읽지 못한 저장소` 경고와 본문이 **서로 다른 말을 한다** | `soilKeyCount`에 **찾은 키 수**를 넘긴다 |
| SUGGESTION | 순수 함수가 마크다운 `**`을 돌려주고 화면이 지우는 구조는 표현 계층이 섞인 형태다 | 순수 함수가 처음부터 일반 텍스트를 돌려주고, 화면의 `replace`를 없앴다 |
| SUGGESTION | 다음 행동을 직접 명령하면 판단 부담이 준다 | "앱에서 접수해 왔다면 앱을 열어 같은 화면에서 다시 실행하세요"를 추가 |
| SUGGESTION | `window.electronAPI?.isElectron` 판정 통일 | **미채택** — 이 파일이 이미 같은 판정을 쓰고 있어 일관되며, 판정 헬퍼 통일은 이 티켓 범위를 넘는다 |

리뷰가 **정상이라고 확인한 것**: 레거시 `soilSampleLogs` 키가 `findSoilStores`에 정상
포함되는 점, `soilSampleLogs`가 다른 시료 접두사에 걸리지 않는 점, `diagnoseEmptyResult`
분기 순서가 정상 입력에서 오분류하지 않는 점, 환경·Firestore 안내가 실제 화면에 나오는 점.

## 남은 한계

- **담당자의 원래 질문은 아직 답이 없다.** 이 수정은 "왜 0건인지"를 화면이 말하게 했을
  뿐이다. 실제 손상 여부는 담당자가 **접수한 환경에서** 다시 실행해야 알 수 있다.
- **Firestore는 여전히 범위 밖이다.** 화면이 그 사실을 말하게 됐을 뿐, 검사하지는 않는다.
  로컬에 없고 클라우드에만 있는 연도는 놓친다.
- 환경 판정 헬퍼 통일(리뷰 SUGGESTION)은 별건으로 남긴다.
- 토양 외 4개 시료 타입의 접수번호는 여전히 검사하지 않는다 — 이 불변식은 토양 성토에만 있다.
