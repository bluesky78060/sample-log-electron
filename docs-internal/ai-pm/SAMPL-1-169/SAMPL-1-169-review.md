# SAMPL-1-169 코드 리뷰 — 가져오기의 클라우드 접수번호 확인

🔴 CRITICAL: 0건 / 🟠 MAJOR: 6건 (전부 수정) / 🟡 MINOR: 0건 / 🔵 SUGGESTION: 0건
→ 판정: APPROVED (독립 리뷰 7라운드)

## 무엇이 없었나

등록(SAMPL-1-167)·수정(SAMPL-1-168)에는 클라우드 확인을 붙였는데 **가져오기에는 없었다.**
미리보기 중복 판정 자체는 있었다(SAMPL-1-153/154) — 로컬 기준이었을 뿐이다.

`computePreview({logs})`가 `logs` 하나에서 세 풀을 모두 도출하므로,
`_existingLogs()`에서 클라우드를 합치면 **수동 중복 판정과 자동부여 회피가 함께** 고쳐진다.

## 독립 리뷰가 잡은 것 — 6라운드 연속 MAJOR

이 티켓은 리뷰가 **여섯 번 연속으로** 실제 결함을 찾았다. 그중 둘은 내가 고친 코드가
새로 만든 것이고, 하나는 내 핵심 수정이 **표시만 고치고 저장은 그대로**였다.

| # | 지적 | 실체 |
| --- | --- | --- |
| 1 | 낡은 응답 처리 | 주석은 "거른다"인데 **거르지 못했다.** 재오픈하면 `_state`가 새 객체라 이전 세션 응답이 새 세션에 들어갔다 |
| 2 | 연도 변경 후 재조회 없음 | 버리기만 해 새 연도는 영영 확인되지 않고 `cloudChecked`가 false로 남아 실패 표시조차 안 떴다 |
| 3 | 조회 완료 후 연도 변경 | 1·2는 **응답 대기 중**만 막았다. 조회가 끝난 뒤 연도를 바꾸면 지난해 캐시가 그대로 쓰였다 |
| 4 | 재계산 없이 커밋 | 연도를 바꾸고 곧바로 저장하면 낡은 미리보기가 그대로 저장됐다 |
| 5a | 재조회 중 두 번째 클릭 | 4번 가드가 재계산을 걸면 `previewYear`는 즉시 갱신되지만 클라우드 응답은 아직 없다 |
| 5b | **표시값 ≠ 저장값** | 커밋 시 자동부여 행의 번호를 지워 매니저가 재부여하는데 매니저는 로컬만 본다 |
| 6 | `getAllWithMeta`도 오류를 삼킨다 | SAMPL-1-167에서 `loadFromFirebase`를 피했으나 **한 겹 아래도 삼키고 있었다** |

### 5b가 가장 뼈아프다 — 이 저장소가 이미 겪은 실패다

테스트로 실증했다:

```
클라우드 1·2 있음 → 미리보기 3·4 → **저장 1·2**
```

내 핵심 수정("자동부여가 클라우드 번호를 건너뛴다")이 **화면만 고치고 저장은 충돌한 채**
두고 있었다. 내 원래 E2E는 미리보기만 단정해서 이것을 통과시켰다.

SAMPL-1-153이 똑같은 실패를 겪었다 — *"미리보기는 1,2,3인데 실제로는 1,1,1"*.
그때 세운 규칙이 **미리보기 = 저장**이고, 그 규칙을 여기서도 지키도록 고쳤다
(`it.display`를 그대로 넘긴다).

### 6은 이 계열 전체에 영향이 있었다

`firestore-db.js`의 catch가 `{documents: [], fromCache: false}`를 돌려줘
**네트워크·권한 오류가 "이 연도에 0건"과 똑같이 보였다.** 등록·수정·가져오기의
사전 검사가 전부 이 위에 올라가 있으므로, 실패한 조회가 "겹치는 번호 없음"으로
조용히 통과했다. `error` 필드를 붙이고 호출부가 그것을 보게 했다 —
빈 배열은 그대로 둬 기존 호출부는 바뀌지 않는다(리뷰 확인).

## 설계 결정

- **저장 직전 재확인은 넣지 않았다.** 미리보기가 담당자의 결정 지점이고, 저장 시점에
  다시 막으면 "덮어쓰기" 선택을 뒤집는다. 리뷰도 타당하다고 판정했다.
  잔여 위험(미리보기 이후의 경쟁)은 SAMPL-1-166의 병합 탐지가 사후에 잡는다.
- **연도 도장이 단일 진실이다.** `_ensureCloudYearFresh`가 캐시를 비우지 않는 이유는,
  비우면 도장 대조가 죽은 코드가 되기 때문이다(변이로 실측). 검사가 한 군데에만
  있는 편이 확인하기 쉽다.
- **연도 변경 시 조용히 재계산해 저장하지 않는다.** 담당자가 본 번호와 저장되는 번호가
  달라진다. 다시 계산해 **보여주고** 한 번 더 누르게 한다.
