# v1.7.81 ~ v1.7.84 변경사항 (2026-03-18)

## v1.7.84 — 자동완성 정확도 개선 + 그룹수정 재검증 + 중복리 감지

### 1. 필지 자동완성 정확도 우선 정렬
- **문제**: "현동리" 입력 시 부분 매칭으로 관련 없는 리가 상위에 노출
- **수정**: 정확 매칭(score 0) > 접두사 매칭(score 1) > 부분 매칭(score 2) 순으로 정렬
- **파일**: `src/bonghwaData.js` — `suggestRegionVillages()`

### 2. "산" 키워드 오탐 수정
- **문제**: "학산리" 입력 시 리 이름 안의 "산"을 산 지번으로 오인하여 "학산리 산" 옵션만 표시
- **수정**: `/\s산(\s|$|\d)/` 정규식으로 지번 앞 독립된 "산"만 감지 (리 이름 내부 "산" 무시)
- **파일**: `src/bonghwaData.js` — `suggestRegionVillages()` L753

### 3. 같은 지역 내 중복 리 감지 (현동리: 소천면/재산면)
- **문제**: `villages` 객체에서 동일 키는 마지막 값만 남아 재산면 현동리가 누락
- **수정**:
  - `suggestRegionVillages()`: `villages` + `duplicates` 합쳐서 모든 (리, 면) 조합 순회
  - `checkCrossRegionDuplicate()`: `duplicates` 데이터도 확인하여 같은 지역 내 중복 감지
  - `parseParcelAddress()`: `villages`에 없으면 `duplicates`에서 폴백 검색
- **파일**: `src/bonghwaData.js`

### 4. 그룹 수정 시 VWORLD 재검증 누락
- **문제**: 필지가 여러 개인 시료(그룹) 수정 시 `addressVerified` 초기화 및 재검증 호출이 없어 빨간색 표시 유지
- **수정**: 그룹 수정 경로(L1800~1814)에 `delete log.addressVerified` + `validateAndMarkLogs(newLogs)` 추가
- **파일**: `src/soil/soil-script.js` — 그룹 수정 분기

## v1.7.83 — VWORLD 필지 검증 totalCount 판정 오류 수정

### VWORLD getCoord API 응답 판정 오류
- **문제**: 코드에서 `response.status === 'OK' && totalCount > 0`을 체크했으나, `getCoord` API 응답에는 `totalCount` 필드가 존재하지 않음. 결과적으로 **모든 유효한 주소가 검증 실패**(빨간색)로 표시됨
- **검증**: `curl`로 직접 VWORLD API 호출 시 `status: "OK"` + `result.point` 정상 반환, `totalCount` 필드 없음 확인
- **수정**: `totalCount` 체크 제거, `status === 'OK'`만으로 유효 판정
- **파일**:
  - `src/soil/soil-script.js` L4441 (웹 환경 fetch 판정)
  - `src/index.js` L915-916 (Electron IPC 핸들러 판정)
