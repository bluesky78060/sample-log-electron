## 1. 기능 1: 검정결과 입력 범위 검증

### 배경

흙토람에 업로드할 검정결과 값에는 각 항목별 유효 입력 범위가 있다.
범위를 벗어난 값을 입력하면 흙토람 시스템에서 오류가 발생하므로,
입력 단계에서 미리 경고하여 잘못된 값을 방지한다.

### 유효 범위 (흙토람 기준)

| 필드명 (코드) | 항목명 | 최소 | 최대 | 단위 |
|---------------|--------|------|------|------|
| `pH` | pH | 3.5 | 9.5 | - |
| `organicMatter` | 유기물 | 1 | 300 | g/kg |
| `availableP` | 유효인산 | 1 | 9999 | mg/kg |
| `exK` | 교환성 칼륨 | 0.01 | 15 | cmol+/kg |
| `exCa` | 교환성 칼슘 | 0.1 | 35 | cmol+/kg |
| `exMg` | 교환성 마그네슘 | 0.1 | 25 | cmol+/kg |
| `silica` | 유효규산 | 5 | 2000 | mg/kg |
| `ec` | 전기전도도 | 0.01 | 30 | dS/m |

#### 1-3. 개별 필드 범위 검증 메서드 (`validateFieldRange`, ~line 603)

```javascript
validateFieldRange(key, field, value) {
    const range = this.fieldRanges[field];
    if (!range) return; // 범위가 정의되지 않은 필드는 스킵

    // 해당 셀 DOM 찾기
    const rowIdx = this.flatRows.findIndex(r => r.key === key);
    const colIdx = this.resultFields.indexOf(field);
    const cell = this.tableBody?.querySelector(
        `td[data-row="${rowIdx}"][data-col="${colIdx}"]`
    );

    // 빈 값 → 경고 제거
    if (!value || value.trim() === '') {
        if (cell) cell.classList.remove('out-of-range');
        return;
    }

    // 숫자가 아닌 값 → 스킵
    const num = parseFloat(value);
    if (isNaN(num)) {
        if (cell) cell.classList.remove('out-of-range');
        return;
    }

    const unitText = range.unit ? ` ${range.unit}` : '';

    if (num < range.min || num > range.max) {
        // ★ 범위 초과: 셀 빨간색 + 토스트 경고
        if (cell) cell.classList.add('out-of-range');
        if (window.showToast) {
            window.showToast(
                `⚠️ ${range.label}: ${num}${unitText} → 입력 범위 ${range.min} ~ ${range.max}${unitText}`,
                'warning'
            );
        }
    } else {
        // 범위 내: 경고 제거
        if (cell) cell.classList.remove('out-of-range');
    }
}
```

**동작 예시:**
- pH에 `10.5` 입력 → 셀이 빨간색, 토스트 "⚠️ pH: 10.5 → 입력 범위 3.5 ~ 9.5"
- pH에 `6.5` 입력 → 정상 (경고 없음)
- pH에 빈값 → 경고 제거

#### 1-4. 테이블 로드 시 기존 데이터 검증 (`validateAllRanges`, ~line 636)

```javascript
validateAllRanges() {
    for (const [key, result] of Object.entries(this.testResults)) {
        for (const field of Object.keys(this.fieldRanges)) {
            if (result[field]) {
                this.validateFieldRange(key, field, result[field]);
            }
        }
    }
}
```

이 메서드는 `renderTable()` 완료 후 호출되어, 이전에 저장된 범위 초과 값도 빨간색으로 표시한다.

## 2. 기능 2: Tab 키 숨김 컬럼 건너뛰기

### 배경

검정결과 필드 16개 중 4개(`soiling`, `clay`, `NO3N`, `NH4N`)는 기본 숨김 상태이다.

```
resultFields 순서 (인덱스):
[0] testDate  [1] soiling(숨김)  [2] clay(숨김)  [3] pH
[4] organicMatter  [5] availableP  [6] exK  [7] exCa
[8] exMg  [9] silica  [10] ec  [11] limeReq
[12] NO3N(숨김)  [13] cec  [14] NH4N(숨김)  [15] usageCode
```

### 문제

Tab으로 `limeReq(11)` → 다음 셀 이동 시 `NO3N(12)`로 이동 시도.
하지만 NO3N은 `display: none` 상태라 포커스 실패 → cec로 넘어가지 않고 멈춤.

**재현**: 석회소요량 셀에서 Tab 키 → 포커스가 사라짐 (cec로 이동 안 됨)

### 수정 내용

#### 2-1. `moveFocus`에 `direction` 파라미터 추가 (~line 564)

**수정 전:**
```javascript
moveFocus(rowIdx, colIdx) {
    if (colIdx >= this.resultFields.length) { colIdx = 0; rowIdx++; }
    if (colIdx < 0) { colIdx = this.resultFields.length - 1; rowIdx--; }
    if (rowIdx < 0 || rowIdx >= this.flatRows.length) return;

    const cell = this.tableBody?.querySelector(...);
    if (cell) cell.focus();
}
```

**수정 후:**
```javascript
moveFocus(rowIdx, colIdx, direction = 1) {
    if (colIdx >= this.resultFields.length) { colIdx = 0; rowIdx++; }
    if (colIdx < 0) { colIdx = this.resultFields.length - 1; rowIdx--; }
    if (rowIdx < 0 || rowIdx >= this.flatRows.length) return;

    // ★ 추가: 숨김 컬럼 건너뛰기 (전체보기 모드가 아닐 때)
    if (!this.showAllColumns && this.hiddenFields.has(this.resultFields[colIdx])) {
        this.moveFocus(rowIdx, colIdx + direction, direction);
        return;
    }

    const cell = this.tableBody?.querySelector(...);
    if (cell) cell.focus();
}
```

**핵심 로직:**
1. 이동 대상 컬럼이 `hiddenFields`에 포함되어 있는지 확인
2. 포함되면 같은 방향(`direction`)으로 한 칸 더 이동 (재귀 호출)
3. `showAllColumns`(전체 보기 모드)가 켜져 있으면 건너뛰지 않음

#### 2-2. 키 이벤트 핸들러에서 방향 전달 (~line 541)

**수정 전:**

**수정 후:**
```javascript
td.addEventListener('keydown', (e) => {
    if (e.key === 'Enter' && !e.shiftKey) {
        e.preventDefault();
        td.blur();
        this.moveFocus(rowIdx + 1, ci, 1);     // ★ 방향: 전진
    } else if (e.key === 'Tab') {
        e.preventDefault();
        td.blur();
        if (e.shiftKey) {
            this.moveFocus(rowIdx, ci - 1, -1); // ★ 방향: 후진
        } else {
            this.moveFocus(rowIdx, ci + 1, 1);  // ★ 방향: 전진
        }
    }
});
```

### Tab 이동 결과 (기본 숨김 모드)

**수정 전:**
```
... → ec → limeReq → [NO3N: 포커스 실패, 멈춤]
```

**수정 후:**
```
Tab (전진):
... → ec → limeReq → (NO3N 건너뜀) → cec → (NH4N 건너뜀) → usageCode → (다음 행)

Shift+Tab (후진):
usageCode → (NH4N 건너뜀) → cec → (NO3N 건너뜀) → limeReq → ec → ...
```

**전체 보기 모드 켜진 경우:**
```
모든 컬럼 순서대로 이동 (건너뛰기 없음)
... → ec → limeReq → NO3N → cec → NH4N → usageCode
```
