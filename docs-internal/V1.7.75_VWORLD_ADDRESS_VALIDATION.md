> 작성일: 2026-03-17
> 티켓: SAMPL-1-14, SAMPL-1-15

## 1. 기능 개요

토양 시료 접수 시 입력된 **필지(지번) 주소**가 실제 존재하는 주소인지 VWORLD 지오코딩 API를 통해 자동 검증합니다. 검증 실패 시 목록 뷰에서 해당 주소를 **빨간색**으로 표시합니다.

### 검증 흐름

```
시료 접수/수정
  → saveLogs() (localStorage 저장)
  → validateAndMarkLogs(newLogs) (백그라운드)
      → 각 필지의 lotAddress를 VWORLD API로 검증
      → log.addressVerified = true/false 설정
      → localStorage 업데이트
      → Firebase 개별 저장 (firebaseSaveRecords)
      → DOM 직접 업데이트 (address-invalid 클래스 토글)
```

## 3. 상세 구현

### 3.1 VWORLD API 호출 (Electron IPC 방식)

VWORLD API는 등록된 서비스 URL에서만 호출 가능합니다. Electron 렌더러의 `fetch`는 `Origin` 헤더가 붙어 도메인 제한에 걸리므로, **main process에서 `node:https`로 직접 호출**합니다.

#### Main Process (src/index.js)

```javascript
ipcMain.handle('vworld-geocode', async (event, { address, apiKey }) => {
    const https = require('node:https');
    const url = `https://api.vworld.kr/req/address?service=address&request=getCoord`
        + `&version=2.0&crs=epsg:4326`
        + `&address=${encodeURIComponent(address)}`
        + `&refine=true&simple=false&format=json&type=parcel`
        + `&key=${apiKey}`;
    return new Promise((resolve) => {
        const timeout = setTimeout(() => { req.destroy(); resolve(null); }, 8000);
        const req = https.get(url, (res) => {
            let data = '';
            res.on('data', chunk => { data += chunk; });
            res.on('end', () => {
                clearTimeout(timeout);
                try {
                    const json = JSON.parse(data);
                    const ok = json?.response?.status === 'OK' &&
                        parseInt(json?.response?.result?.totalCount ?? '0', 10) > 0;
                    resolve(ok);  // true: 주소 존재, false: 주소 없음
                } catch { resolve(null); }  // null: 판단 불가
            });
        });
        req.on('error', () => { clearTimeout(timeout); resolve(null); });
    });
});
```

- **타임아웃**: 8초 (무응답 시 `null` 반환)
- **반환값**: `true` (주소 존재) / `false` (주소 없음) / `null` (판단 불가)

### 3.2 주소 검증 함수 (soil-script.js)

#### validateParcelAddress(lotAddress)

```javascript
async validateParcelAddress(lotAddress) {
    if (!lotAddress || lotAddress === '-') return null;
    if (!navigator.onLine) return null;
    const apiKey = window.NETWORK_CONFIG?.VWORLD_API_KEY;
    if (!apiKey) return null;

    // bonghwaData 주소 형식 보정: "봉화군 ..." → "경상북도 봉화군 ..."
    const SIDO_RE = /^(서울|부산|대구|인천|광주|대전|울산|세종|경기|강원|...)/;
    const fullAddress = SIDO_RE.test(lotAddress) ? lotAddress : `경상북도 ${lotAddress}`;

    // Electron: main process IPC (Origin 헤더 없음 → 도메인 제한 우회)
    if (window.electronAPI?.vworldGeocode) {
        return await window.electronAPI.vworldGeocode(fullAddress, apiKey);
    }

    // 웹: 직접 fetch (등록된 도메인에서만 작동)
    // AbortController 8초 타임아웃 포함
}
```

**bonghwaData 주소 보정**:
- `bonghwaData.js`의 주소 형식: `"봉화군 봉화읍 내성리 123"`
- VWORLD API 요구 형식: `"경상북도 봉화군 봉화읍 내성리 123"`
- 시도명이 없으면 자동으로 `"경상북도 "` prefix 추가

### 3.3 검증 트리거 시점

### 주의사항

1. **network-config.js**: `.gitignore`에 포함되므로 테스트 프로젝트에 수동 복사 필요
2. **VWORLD API Key**: 동일 키 사용 가능 (서비스 URL에 localhost 등록 필요 시 별도 설정)
3. **Electron 전용 기능**: 웹 환경에서는 VWORLD 서비스 URL 도메인 제한으로 작동하지 않을 수 있음
4. **암호화 코드 보존**: `soil-script.js` 복사 시 테스트 프로젝트의 `encryptionManager` 관련 코드 보존 필요
