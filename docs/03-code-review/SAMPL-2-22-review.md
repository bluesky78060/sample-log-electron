## 리뷰어가 검증해 준 사항

- `local_sha` 삭제 감지 `*[!0]*` — **POSIX 정확**, 삭제 푸시 시 검사 미실행 확인
- force push / 첫 푸시(`remote_sha`=0) — `local_sha`만 보므로 **양쪽 정확**
- 다중 ref 동시 푸시 — 3 refs 재현 시 검사 3회 실행, 깨진 ref에서 차단.
  **`node`가 `while read`의 stdin을 잠식하지 않음** 확인(흔한 훅 버그인데 없음)
- 비범위 3건 모두 타당: 고아 자산 **실측 0개**, CSS `url()` 로컬 대상 1건(폰트 열화 수준),
  진짜 동적 `import()` **0건**이라 JS 미스캔의 미탐 위험 없음
- `sh -n`·`dash -n` 모두 통과 (POSIX 청결)
